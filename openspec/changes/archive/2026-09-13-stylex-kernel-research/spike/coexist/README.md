# spike/coexist — Tailwind 4 + StyleX coexistence (the D2 matrix)

Three production builds of the same app + one hoisted-statement
diagnostic:

| build | config | outDir |
|---|---|---|
| CONTROL | TW-only, zero stylex (`STYLEX_LAYER=off`) | dist-control |
| O1 | `useCSSLayers { prefix:'stylex', after:['utilities'] }` | dist-o1 |
| O2 | `useCSSLayers { prefix:'stylex', before:['utilities'] }` (misconfig) | dist-o2 |
| O1-H | O1 + layer statement hoisted above `@import 'tailwindcss'` | dist-o1h |

## From zero to run

```bash
cd spike/coexist
npm install
npm run build:all      # sync app.css → control → o1 → o2 (serial)
npm run build:o1h      # the hoisted-statement DIAGNOSTIC build
npm run probe:d2       # all 15 D2 rows + D1-10(prod) + D1-11(prod); serves each dist serially
node scripts/probe-d1-dev.mjs   # D1-10(dev) on the vite dev server (records the dev layer hazard)
ENGINE=webkit node scripts/probe-d2.mjs   # WebKit run
```

`src/app.css` is GENERATED by `scripts/sync-app-css.sh` (byte-copies
the D2 manifest's anchored repo blocks; prints the sha256 of every
range). Never hand-edit it — re-run `npm run sync-css`.

## The two headline results

1. **D2-01/D2-03 FAIL under the frozen app.css order**: unplugin
   0.19.0 appends stylex css AFTER TW's utilities block → stylex
   layers are inscribed LAST → stylex always wins over consumer
   utilities in BOTH O1 and O2. The `after:['utilities']` config
   alone cannot deliver the manifest's O1 expectation.
2. **O1-H proves the remedy**: hoisting
   `@layer properties, theme, base, components, stylex.priority1..3, utilities;`
   ABOVE the import (CSS-legal — @layer statements may precede
   @import) restores 42px / red-500 / all O1 expectations, with TW's
   internal layer order preserved.

## Dev-mode hazard (recorded, not fixed)

On the vite dev server the `/virtual:stylex.css` style tag inscribes
the stylex layers BEFORE app.css's TW layers → TW **base** (preflight
`padding:0`) beats the stylex layers → K padding collapses to 0 in dev
while prod computes 16px. D1-10(dev) therefore FAILs here and PASSES
on spike/ssg's dev (which uses `runtimeInjection` — unlayered dev
rules). Details in the spike report.
