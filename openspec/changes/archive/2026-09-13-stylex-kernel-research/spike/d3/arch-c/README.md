# d3/arch-c — precompiled css + class constants

D3 fixture, architecture C (channel-collapse §3 column C). Same shell + the 8 frozen
families, shipped as COMPILED artifacts: every `*.stylex.ts` replaced by its babel output
(`*.stylex.js` — class-constant modules) + `src/kernel-precompiled/stylex.css` (439 rules,
processStylexRules + lightningcss, the same pipeline the unplugin runs at build time).
The consumer keeps `@stylexjs/stylex` as a RUNTIME dependency (styleq for attrs()/dynamic
merging) and adds ONE css import in `src/main.ts`. No babel/unplugin anywhere in the
consumer build.

The artifacts are generated by `../precompile/` (kernel-build side — its dependency closure
prices on OUR side, not the consumer's; the exact command is in research/d3-consumer.md).

## Exact rerun

```bash
cd spike/d3/precompile && npm ci && node precompile.mjs   # regenerates arch-c/src artifacts
cd ../arch-c
npm ci
npx vite build
```

Pins: svelte 5.57.0, vite 8.3.0, @stylexjs/stylex 0.19.0 (runtime),
@sveltejs/vite-plugin-svelte 7.3.0, typescript 5.9.3 (exact, no ^).
