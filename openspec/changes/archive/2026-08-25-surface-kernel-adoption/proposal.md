# surface-kernel-adoption — 11 floating surfaces join the shared motion kernel

> Owner request (2026-08-25): dropdown-menu uses the popover laws but
> has no open/close animation — the kernel is opt-in per component and
> was never wired. Audit found 11 popover-flavor surfaces in the same
> state. Owner ruling: Popover is the base component; every floating
> layer adopts the SAME kernel technology (registry/files/lib/
> surface-motion.ts), no per-component improvisation.

## Inventory (the audit)

Kernel adopters (unchanged): popover, dialog, alert-dialog, command
(shared createSurfaceMotion) + tooltip (hand-rolled choreography —
legitimate: the notch-mask silhouette needs custom WAAPI, declared in
its header). Consumers inheriting via popover.svelte (unchanged):
navigation-menu, terminal-header.

Sheet: EXCLUDED by design — a declared POSITIONING/ANIMATION variant
(edge slide + .closing, Codex r2 timing exception), already animated.

The 11 adopters (popover flavor, all with .jx-surface + .jx-surface-body
structure already in place):

```
popover=auto   dropdown-menu  select  combobox  tags-input
               date-picker  color-picker  popconfirm  float-button
popover=manual hover-card  menubar  tour
```

## What Changes

Per component, the popover.svelte wiring VERBATIM (no choreography
changes — the CSS formula layer in jixoai.css is global and complete):

1. `createSurfaceMotion(() => panel, { anchor: () => anchorWrap })`
2. toggle seam plays `motion.play(1)+startTracking()` on open,
   `classList.remove('jx-rest')+motion.play(0)+stopTracking()` on close
   — via the existing ontoggle seam where present (Pattern P:
   dropdown-menu/select/combobox/tags-input/date-picker/color-picker/
   popconfirm/menubar/float-button), or imperatively at the show/hide
   call sites (Pattern C, command.svelte's shape: hover-card, tour)
3. panel class gains `motion.supported && 'jx-waapi'` (the CSS gate)
4. a REAL `.jx-surface-shadow` DOM child (first child of the panel —
   r18 law: pseudo-elements are unreachable from WAAPI)
5. `onDestroy(() => motion.destroy())`

jixoai.css needs NOTHING (formulas, ::after disable, allow-discrete
window, no-JS + reduced-motion fallbacks are all keyed off .jx-waapi).
