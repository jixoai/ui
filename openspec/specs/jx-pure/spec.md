# jx-pure — the componentless face (living spec)

> Capability owner: registry/files/theme/jx-pure.css (+ its mirrors:
> apps/www/src/lib/jx-pure.css, public payloads via the build pipeline).
> One stylesheet, zero JS: mount `jx-pure` on any DOM and the subtree's
> bare native elements carry the jixoai law.

## Current contract (state: 2026-08-24, post r7)

- **Part A — class vocabulary** (unlayered, Tier-2 frozen contract):
  .jx-field / .jx-label / .jx-error / .jx-input / .jx-field-shell /
  .jx-input-lane / .jx-range / .jx-color-field / .jx-color + icon
  custom properties.
- **Part B — element defaults** (`@layer components`, `:where(.jx-pure)`
  scoped): typography, links, buttons (press variable contract),
  type-allowlist text lanes, checkbox/radio/range/color repaints,
  fieldset/legend, details/summary, nav/ol/ul/dl, tables,
  progress/meter/output, figure/figcaption + media, switch
  ([role=switch]), the aria-invalid matrix, the escape hatch.
- **Part C — degradation laws**: full-stillness reduced-motion (per
  engine surface), forced-colors reversion to native paint.
- **Part D — auto-dark** (GENERATED by scripts/gen-jx-auto-dark.mjs
  from jixoai.css's .dark block; single source, parity-locked):
  `.jx-auto-dark` gates prefers-color-scheme:dark with .dark priority
  and .jx-light exclusions.
- **Boundaries**: floating surfaces (dialog/popover/tooltip) stay
  Tier-2; document CSS never crosses shadow roots (CustomElements
  adopt the sheets themselves — see the docs page's live island);
  registry `native-form` is a same-source deprecated alias.

This living spec is amended only through OpenSpec changes (see
changes/). History of the pre-OpenSpec era lives in git history
(.scratch was removed when OpenSpec was adopted, 2026-08-24).
